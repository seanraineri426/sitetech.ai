# SiteTech vs Procore AI: positioning (Product, Oct 9 2026)
Sources: procore.com/ai/agents, procore.com/ai/plans, Procore/Datagrid press release (Jan 20 2026), Procore support "Which agents are included".

## What Procore ships
- Datagrid acquired Jan 2026. Procore AI is sold as "Digital Coworker" packages: Starter (5 agents, flat fee), Pro (20 agents, credits, incl. RFI- and Submittal-triggered agents, scheduled automations), Enterprise (Agent Studio custom agents, BI connection, deployment support). Not per-seat.
- Agents include: RFI Agent (drafts RFIs), Submittal review vs specs/contracts, Daily Log Agent (photos/notes/voice/email → logs), Contract Review, Deep Search, Meeting Minutes Publisher Agent (Pro).
- Human-in-the-loop on everything. Datagrid connects third-party sources (ERP, cloud storage) and is offered to non-Procore customers too.

## Don't build
RFI drafting from field notes; daily logs; submittal-vs-spec checks; generic meeting minutes. Procore does these inside the PE's existing screen.

## Where SiteTech wins
1. **Cross-system judgment tied to money.** Slips, notices, and owner directives arrive in email; float lives in P6; commitments happen in meetings. We connect an event in any system to float and $ and prepare the action that protects them.
2. **Developer/owner side.** Developers usually aren't the Procore licensee and work with GCs on different systems. Cross-project, cross-GC view tied to IRR.
3. **Outcome proof.** Float days protected × daily delay cost, change $ captured. Procore meters credits.
4. **Partner, not rival.** Procore Marketplace app; M3 write-back creates Procore CEs, tasks, meeting items. We make Procore data more valuable.
5. **Not Procore-only.** Email + meetings + P6 work for non-Procore jobs.

## Risk
Datagrid adds email + P6 and does cross-system $ judgment. Defense: speed, depth on email/schedule judgment, owner side, a proven ROI number on a real project first. Watch Procore release notes monthly.
