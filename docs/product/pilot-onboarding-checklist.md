# Pilot onboarding checklist (Product; replaces the lost one-pager checklist, Oct 9 2026)
| Who | Action |
|---|---|
| Customer exec | Written OK to connect one project (store + process Procore data, full project-mailbox email text, meeting transcripts in the project Space) |
| M365 admin | Admin consent to the SiteTech Data Connector app: Mail.Read on the one project mailbox (Exchange RBAC for Applications, no tenant-wide Mail.Read), Sites.Selected on one site |
| Procore admin | Install SiteTech custom app (DMSA, read-only template, pilot project only) |
| Granola admin | Business/Enterprise; one Space per project; API key to SiteTech; opt out of training on de-identified data |
| PX / PM | Recording consent from everyone in recorded meetings where state law requires all-party consent; announce at start of each recorded meeting |
| PX | Roles: name the PE, PM, PX (and super) for the project |
| PX | Daily delay cost (GC general conditions + owner carry) |
| PX | Contract notice periods: type (delay/time, cost/change claim, differing site condition, change directive dispute, cure/default, injury/property damage), days, calendar vs business, contract section, for owner contract + major subs |
| PX | Project parties: company, email domain, role (owner, architect_engineer, gc, sub) |
| PX | Project time zone + observed holidays |
| PE | Where the live schedule is (Procore or P6; weekly XER if P6) |
| PE | Use the action queue for 30 days; 15-min check-in weekly; PX scorecard at day 30 |
