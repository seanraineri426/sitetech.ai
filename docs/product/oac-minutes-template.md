# SiteTech OAC Meeting Minutes Template (Product, Oct 9 2026)
Built on Procore Meetings' own structure (meeting → categories → items with agenda #, title, description, priority) so minutes paste into Procore (M2) and write back via meeting topics (M3).

## Header
Project · Meeting type (OAC / Sub coordination / Owner) · Meeting # · Date, time, timezone · Location / link · Attendees (name, company, role, present/absent) · Distribution · Next meeting

## Categories (fixed order)
1. Safety
2. Schedule: critical path, slips, 2-week lookahead
3. RFIs: open / overdue
4. Submittals
5. Procurement & long-lead
6. Changes: PCOs / change events
7. Owner decisions
8. Field, quality, inspections
9. Old business (carried over)
10. New business

## Every item
| Field | Rule |
|---|---|
| Item # | Category.sequence (e.g. 3.04); stays the same across meetings |
| Title | Plain language |
| Discussion | 1–3 sentences |
| Status | Open / Closed / On hold |
| Ball in court | Company + person; unknown speaker = "confirm owner" |
| Due date | Stated date, or "none stated" |
| Linked record | RFI / submittal / CE / schedule activity, if any |
| Days / $ at risk | From code only, same rules as actions; else blank |
| Source | Transcript quote + timestamp |
| Commitment? | Yes = becomes a tracked action (A8) |

## Rules
- Open items carry forward automatically with their original item #.
- Owner decision with cost and no CE → change-event action (A9).
- Missed commitment → chase draft the morning after the due date.
- No legal conclusions. Distribution note: "Please send corrections within 5 business days."
- PM approves before distribution.
